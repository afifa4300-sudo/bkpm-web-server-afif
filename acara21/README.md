## 1. Ringkasan Praktikum
Pada Acara 21, disusun dokumentasi teknis formal dari seluruh API yang telah dikembangkan sejak Acara 17 hingga 20. Dokumentasi teknis ini disimpan pada berkas:
- **Lokasi Dokumen**: `docs/API_DOCUMENTATION.md`

## 2. Fitur Dokumentasi
1. **Tabel Ringkasan Endpoint**: Memuat HTTP Method, Endpoint, Fungsi, Status Autentikasi, dan Controller Penanggung Jawab (*Tugas Praktik Mandiri*).
2. **Keterangan Header & Security**: Menjelaskan penggunaan `Authorization: Bearer <token>` untuk endpoint POST, PUT, dan DELETE.
3. **Contoh Request & Response**: Memuat contoh JSON masukan dan contoh respon berstatus `200 OK`, `201 Created`, `400 Bad Request`, `401 Unauthorized`, `404 Not Found`, serta `422 Unprocessable Entity`.
